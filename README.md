# High-Throughput Sequencing & Multi-Omics Workflows

End-to-end bioinformatics analyses covering epigenomics, metagenomics, functional enrichment, and transcriptomics.

## Repository Structure

* **`01_ChIPseq_DiffBind/`** — Differential binding analysis of ChIP-seq peak data using R/Bioconductor (`DiffBind`, `DESeq2`). [View Report](./01_ChIPseq_DiffBind/report/ChIPseq_DiffBind_Analysis.pdf)
* **`02_16S_Microbiome_QIIME2/`** — 16S rRNA amplicon denoising (DADA2), taxonomic profiling, and diversity metrics in `QIIME 2`. [View Report](./02_16S_Microbiome_QIIME2/report/16S_rRNA_QIIME2_Analysis.pdf)
* **`03_Functional_Annotation/`** — Gene Ontology (GO) term enrichment and pathway perturbation analysis. [View Report](./03_Functional_Annotation/report/Functional_Enrichment_Analysis.pdf)
* **`04_RNAseq_and_NGS_Labs/`** — Core sequence processing, quality control, alignment, and downstream statistical analysis. [View Reports](./04_RNAseq_and_NGS_Labs/report/)
